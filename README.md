## 🛠️ MCP Tools Exposed
- `calculate_melanopic_equivalent_daylight_lux`: Convert photopic lux to Melanopic Equivalent Daylight Lux (m-EDI) for indoor office lighting.
- `synthesize_nocturnal_display_filter_profile`: Generate night-shift display color temperature curve (6500K to 1900K) to preserve melatonin.
